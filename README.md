# Bond 009: Paris Flash Episodes

A standalone, browser-playable HTML action game featuring Agent **Takumi Bond (Code 009)** in fast, non-overarching episodes set in everyday Paris locations.

## Play

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- `WASD` / Arrow Keys: Move
- `Space`: Close strike / interact
- `Shift`: Dash burst
- `P`: Pause
- `Generate New Standalone Episode`: Start a new independent mission
