# Agent E-006: Paris Field Episodes

Standalone browser FPS action prototype built with Three.js.

## Run

Open `index.html` in a modern browser with network access (CDN import for Three.js), or serve locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Design constraints implemented

- Fixed protagonist identity: Agent E-006 (no random name, no Bond surname).
- 007-like inspired gun barrel intro at UI start.
- Procedural standalone Paris mission episodes with no overarching story or cliffhanger.
- Everyday Paris environments with high-intensity action gameplay.
- Fictional international agency and malicious opposition without terrorism, corruption, crime, or rogue-agent plotlines.
